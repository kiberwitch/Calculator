
### Этот **интуитивно понятный и стильный калькулятор** разработан с использованием чистого **HTML, CSS и JavaScript**. Он имитирует дизайн и функциональность стандартного iOS-калькулятора, но с улучшенной анимацией и плавной работой.  

---

## 🔹 **Ключевые особенности**  

### **1. Дизайн и интерфейс**  
- **Минималистичный черный дизайн** с закругленными углами (как в iOS)  
- **Крупные цифры** на дисплее для удобного чтения  
- **Анимированные кнопки** с эффектами при наведении и нажатии  
- **Адаптивная верстка** — корректно отображается на любых устройствах  

### **2. Функциональность**  
✅ **Базовые операции**:  
   - Сложение (`+`), вычитание (`-`), умножение (`×`), деление (`÷`)  
   - Процентные вычисления (`%`)  
   - Смена знака (`+/-`)  

✅ **Дополнительные возможности**:  
   - Работа с десятичными числами (кнопка `.`)  
   - Сброс (`AC`) — очищает всё  
   - Последовательные вычисления (например, `5 + 3 × 2 = 11`)  

✅ **Логика обработки ошибок**:  
   - Защита от двойных операторов (`++`, `--`)  
   - Корректная работа с десятичной точкой (нельзя ввести `5..2`)  

### **3. Техническая реализация**  
- **Чистый JavaScript** (без jQuery и сторонних библиотек)  
- **Гибкая система состояний**:  
   - `currentInput` — текущее значение на экране  
   - `firstOperand` — первый операнд для вычислений  
   - `operator` — выбранный оператор (`+`, `-`, `×`, `÷`)  
   - `waitingForSecondOperand` — флаг ожидания второго числа  

- **Оптимизированный CSS**:  
   - Grid-раскладка для кнопок  
   - Плавные hover-эффекты  
   - Кастомные стили под темную тему  

---

## 🔹 **Как это работает?**  

### **1. Ввод чисел**  
- При нажатии цифры значение выводится на экран.  
- Если введено `0`, оно заменяется на новую цифру (чтобы избежать `0123`).  

### **2. Операторы (`+`, `-`, `×`, `÷`)**  
- При выборе оператора запоминается первое число (`firstOperand`).  
- Калькулятор переходит в режим ожидания второго числа (`waitingForSecondOperand = true`).  

### **3. Кнопка `=` (равно)**  
- Выполняет вычисление и выводит результат.  
- Если нажать `=` несколько раз, повторяет последнюю операцию (например, `5 + 3 = 8`, затем `= +3 → 11`).  

### **4. Специальные функции**  
- **`AC`** — полный сброс (обнуляет всё).  
- **`+/-`** — меняет знак числа (положительное ↔ отрицательное).  
- **`%`** — делит число на 100 (полезно для процентов).  
- **`.`** — добавляет десятичную часть (но только одну точку в числе).
